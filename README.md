## What I'm Building

Everything below runs on **Claude Code** — zero external AI API keys needed. Clone, install, run.

### Investment Research Pipeline

| Project | Stack | What It Does |
|---------|-------|--------------|
| [**nse-tracker**](https://github.com/nimitmehra/nse-tracker) | Python · Playwright · Claude Code | Automated NSE stock screening — downloads investor presentations, scrapes financials from Screener.in, applies 3-tier filters, and runs deep research via Claude Code |
